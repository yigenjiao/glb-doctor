# 小红书「小工具」版

小红书小工具要求作品纯前端、离线可用、不发起外部网络请求。`build.py` 从根目录的 `index.html` 自动生成符合要求的版本，原页面不改动。

```bash
python3 xhs/build.py
# → dist/glb-doctor-xhs.zip（index.html 在 zip 根目录，直接上传到 Builder Hub → 小工具）
```

## 和网站版的区别

- 去掉 Google Fonts，改用系统字体
- 顶栏 GitHub 链接改成纯文字，不跳站外
- 两个样本 GLB 以 base64 内嵌，不再 fetch
- 「下载修复文件」「导出报告」改成底部保存面板：系统分享（支持时）/ 直接下载 / 复制报告全文
- 「拖进来」文案改成「选择」；手机竖屏欢迎框收紧，未加载模型时隐藏视图工具栏
- 只打包运行需要的文件（不含 docs、README、样本生成脚本）

修改 `index.html` 后重新运行即可。如果原页面里被替换的片段改了，脚本会直接报错并指出是哪一段，不会悄悄生成坏包。
